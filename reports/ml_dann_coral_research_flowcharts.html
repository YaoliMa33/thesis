0. 共同输入与符号表 shared notation

Source / train 数据

X_s ∈ RN_s × 54
  • N_s：source 或训练 trial 数
  • 54：6 个传感器 × 9 个 trial-level 特征
  • y_s ∈ {0,1,2}N_s，三类：air / alcohol / acetone

Target / test 数据

X_t ∈ RN_t × 54
  • N_t：target-domain trial 数
  • DANN/CORAL 可使用 target features
  • UDA 训练中不使用 target gas label

类别与输出

C = 3
  • 分类输出 logits：z ∈ RN × C
  • 概率：g = softmax(z) ∈ RN × C
  • 预测类别：ŷ = argmax(g)
符号维度代码对应含义
X, X_s, X_tN × 54source_x, target_domain_x, x_train_raw每个 trial 的 54 维传感器特征
y, y_sNy_train, y_source, y_cls气体类别标签，air/alcohol/acetone 编码为 0/1/2
hN × 16FeatureExtractor: 54 -> 32 -> 16DANN/CDAN/C-DANN 的共享潜在表示
G_f54 -> 16FeatureExtractor共享特征提取器
G_y16 -> CLabelClassifier气体分类器
G_d16 -> 2DomainClassifierDANN 域判别器：source vs target
G_cd16C -> 2 = 48 -> 2CDANDomainDiscriminatorCDAN 条件域判别器
y_domN_s + N_tzeros(source), ones(target)域标签：0=source, 1=target

1. ML baseline 总流程 LDA / LR / kNN / RF / SVM / MLP

输入特征表

X ∈ RN × 54, y ∈ {0,1,2}N
  • 来自 manifest_baseline_as_air_features.csv
  • 可从 raw CSV 重建特征表
→

时间划分 S1-S7

D = D_train ∪ D_val ∪ D_test
  • 训练 / 验证 / 测试互斥
  • S1 无验证集，使用默认参数
  • S2-S7 使用验证集选参
→

StandardScaler + 模型

Z = (X - μ_train) / σ_train
  • Pipeline: scale -> model
  • 验证集选择超参数
→

输出

ŷ_test ∈ {0,1,2}N_test
  • accuracy
  • balanced accuracy
  • macro-F1
  • confusion matrix

模型集合

  • LDA: shrinkage ∈ {0.01, 0.1, 0.25, 0.5}
  • Logistic Regression: balanced class weight
  • kNN: n_neighbors ∈ {1,3,5,7}
  • Random Forest: 300 trees, balanced class weight
  • RBF SVM: balanced class weight
  • MLP: hidden layer h ∈ {8,16,32}

训练目标 / loss

LR / MLP: L_cls = CE(y, G(X)) + regularization
SVM: max-margin hinge objective
RF / kNN / LDA: 非神经网络分类目标
代码层面统一通过 sklearn fit() 训练，不显式手写 loss。

模型选择

score = (macro-F1, balanced acc, acc)
  • 验证集存在：按 score 选最优超参数
  • 无验证集：使用 DEFAULT_PARAMS
  • test 只用于最终评估，不参与调参

2. CORAL 传统无监督对齐 probe actual code: not neural CORAL loss

重要边界：当前代码中的 CORAL 不是在神经网络中优化 L_CORAL，而是传统特征空间对齐：对 source 特征做白化和重着色，使 source 协方差接近 target 协方差，然后用 nearest-centroid 分类器评估 target。

Source 特征

X_s ∈ RN_s × 54
  • 含 source gas labels y_s
  • 用于计算 source 均值和协方差

Target 特征

X_t ∈ RN_t × 54
  • 训练对齐时隐藏 target labels
  • 用于计算 target 均值和协方差

均值与协方差

μ_s = mean(X_s), μ_t = mean(X_t)
C_s = cov(X_s - μ_s) + 10^-4 I
C_t = cov(X_t - μ_t) + 10^-4 I
C_s, C_t ∈ R54 × 54
CORAL align source to target covariance

Source whitening + target recoloring

X_s^CORAL = (X_s - μ_s) C_s^{-1/2} C_t^{1/2} + μ_t
  • 输入：X_s, X_t
  • 输出：X_s^CORAL ∈ RN_s × 54
  • target features 不被改写

评估输出

ŷ_t = nearest_centroid(X_s^CORAL, y_s, X_t)
  • 输出 target prediction：ŷ_t ∈ {air, alcohol, acetone}N_t
  • 报告 target accuracy / balanced accuracy
  • 诊断距离：||C_s - C_t||_F / (4d²), d=54

3. DANN family 共同骨架 G_f / G_y / domain heads

分类训练输入

X_cls ∈ RN_cls × 54
  • UDA: source labels only
  • semi: source labels + selected target labels
  • y_cls ∈ {0,1,2}N_cls

域对抗输入

X_dom = [X_s; X_t]
  • X_dom ∈ R(N_s+N_t) × 54
  • y_dom = [0...0, 1...1]

共享特征提取器 G_f

54 -> 32 -> 16
  • h = G_f(X)
  • h_s, h_t ∈ RN × 16
  • Dropout(0.05) + ReLU

分类头 G_y

16 -> C, C=3
  • logits z = G_y(h)
  • g = softmax(z)
  • ŷ = argmax(g)
UDA: target features 可用于域损失，但 target gas labels 不用于分类损失。
semi: 代码允许 selected target labels 进入分类训练和 C-DANN centroid target。
模型选择: 有验证集时按 macro-F1 -> balanced accuracy -> accuracy 选择。

4. DANN 详细流程 DANN-UDA / DANN-semi

分类路径

X_cls -> G_f -> h_cls -> G_y -> z_cls
  • h_cls ∈ RN_cls × 16
  • z_cls ∈ RN_cls × 3

域路径

X_dom -> G_f -> h_dom -> GRL -> G_d
  • h_dom ∈ R(N_s+N_t) × 16
  • domain logits ∈ R(N_s+N_t) × 2

Loss

L = CE(z_cls, y_cls)
L_d = CE(G_d(GRL(h_dom)), y_dom)
backward scalar = L + L_d

GRL 实际含义

feature objective: min L - λL_d
  • forward 不改变 h
  • backward: grad -> -λ grad
  • λ ∈ {0.05, 0.2, 0.5}

输出

训练完成得到 G_f, G_y, G_d；target 预测为 ŷ_t = argmax(G_y(G_f(X_test)))
记录 train / validation / test accuracy, balanced accuracy, macro-F1, domain discriminator accuracy。

5. Official CDAN 详细流程 conditional adversarial

共享表示与类别概率

h = G_f(X) ∈ RN × 16
z = G_y(h) ∈ RN × 3
g = softmax(z) ∈ RN × 3

条件映射 T(h,g)

T(h,g) = g ⊗ h
T ∈ RN × (3·16) = RN × 48
代码中 detach_predictions=True，domain loss 不通过 g 更新分类器。

条件域判别器 G_cd

48 -> 32 -> 2
  • 输入：T(h,g)
  • 输出：source/target logits
  • 通过 GRL 做对抗训练
classification + conditional domain adversarial loss

Loss

L = CE(G_y(G_f(X_cls)), y_cls)
L_d^CDAN = CE(G_cd(GRL(T(h_dom,g_dom))), y_dom)
backward scalar = L + L_d^CDAN

输出

  • 训练后模型：G_f, G_y, G_cd
  • target prediction：ŷ_t = argmax(G_y(G_f(X_test)))
  • 记录 L_last, Ld_cdan_last, validation/test metrics

6. Custom C-DANN 详细流程 class-wise centroid alignment

方法边界：这里的 C-DANN 是本项目自定义 centroid alignment，不是 official CDAN。它复用 DANN 的 G_f/G_y/G_d，再额外计算 class-wise latent centroid loss L_c。

Source latent centroids

h_s = G_f(X_s) ∈ RN_s × 16
W_s = onehot(y_s) ∈ RN_s × 3
M_s = W_s^T h_s / sum(W_s)
M_s ∈ R3 × 16

Target latent centroids

h_t = G_f(X_t) ∈ RN_t × 16
UDA: W_t = softmax(G_y(h_t))
semi: W_t = onehot(y_t_labeled)
M_t ∈ R3 × 16

Centroid alignment loss

L_c = mean((M_s - M_t)^2)
  • 输出：scalar
  • 强度：α ∈ {0.05, 0.2, 0.5}
  • 缺类别权重时显式报错
DANN loss + class-wise centroid loss

Total objective

L_total = L + L_d + αL_c
feature objective through GRL: min L - λL_d + αL_c

输出与诊断

  • target prediction：ŷ_t
  • training curves: L, Ld, Lc, total_loss
  • domain discriminator accuracy
  • latent mixing diagnostics: centroid distance / neighbor mixing

给绘图模型/ChatGPT 的结构要求

  • 先画共同输入：X_s, X_t ∈ R^{N×54}，C=3。

避免画错
